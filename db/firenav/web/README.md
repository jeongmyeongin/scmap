# 3단계 지도 기반 기본 웹앱

Next.js 15 + React 19 + TypeScript, 정적 사이트로 내보내기(서버 없음). 카카오 지도 JavaScript SDK 사용.

## 기능 (이번 단계)

| 기능 | 상태 |
| --- | --- |
| 카카오 지도 표시 (첫 화면: 순천시청 부근) | 구현, **실제 지도 표시는 미검증** (아래 참고) |
| 현재 위치 표시·정확도 원 | 구현, 실제 휴대폰에서 미검증 |
| 주소 검색 / 장소명 검색 (탭으로 선택, 1회 검색 = 1회 호출) | 구현, 실제 카카오 응답으로 미검증 |
| 출발지(기본: 현재 위치)·목적지 지정, 지도 눌러 목적지 선택 | 구현 |
| 직선거리 표시 | 구현 (경로 거리가 아님) |
| 차량별 경로 탐색 | **미구현** (7·8단계) |
| DB(Supabase) 연결 | **미구현** (4단계) |
| 음성 안내·경로 이탈 재탐색 | **미구현** (9단계) |
| 오프라인 동작 | **미구현** |

## 카카오 쿼터 보호 (검증 보고서 3-1 적용)

- 글자 입력마다 검색하지 않음. 검색 버튼·엔터에서만 호출.
- 같은 검색은 10분간 기기 안에서 재사용(서버 저장 없음). 장소명 검색은 지도 중심 약 1km 단위로 구분.
- 같은 검색 동시 요청 1회로 합침, 1.5초 안 연속 검색 차단.
- 검색 오류 2회 연속 시 10분간 검색 중지. 지도·현재 위치·지도에서 목적지 선택은 계속 동작.
- 카카오 SDK는 HTTP 429(쿼터 초과)를 다른 오류와 구분해 알려주지 않는다 [판단: SDK 콜백은 OK·ZERO_RESULT·ERROR만 전달]. 그래서 "오류 반복 = 쿼터 초과 가능성 포함"으로 처리한다.
- 이 기기의 오늘 검색 호출 횟수만 표시(숫자만 저장). 앱 전체 사용량은 카카오가 제공하지 않아 알 수 없다.
- 출발지는 현재 위치가 기본값이라 출발지 검색을 생략할 수 있다.

## 직접 실행 (선택 — Node.js 20 이상 필요)

```bash
cd web
cp .env.example .env.local     # .env.local에 카카오 JavaScript 키 입력
npm install
npm run dev                    # http://localhost:3000
npm test                       # 단위 테스트
```

## 비밀값

- 넣는 키는 **JavaScript 키 하나뿐**이다. 브라우저에 노출되는 용도의 키이며, 카카오 앱에 등록한 사이트 도메인에서만 동작한다.
- REST API 키·Admin 키는 이 앱에 넣지 않는다.
- `.env.local`은 GitHub에 올라가지 않는다(`.gitignore`). 배포 시 키는 Cloudflare 설정 화면에만 입력한다.
