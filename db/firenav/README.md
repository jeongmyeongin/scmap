# 소방차량 맞춤형 안전경로 안내 시스템

차량별 제원(전고·전폭·전장·중량·축중량·회전반경)과 도로 제한정보를 비교해, 해당 소방차가 통행하기 어려운 구간을 표시하고 대체 경로를 찾는 반응형 웹앱. 최초 적용: 전라남도 순천소방서 관할.

> **참고용 시스템이다.** 경로 안내는 현장 상황과 지휘 판단을 대체하지 않는다. 실증 완료 전에는 실제 출동의 주 내비게이션으로 쓰지 않는다.

## 진행 상황

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1 | 기술 조사·아키텍처 | 완료 (검증 보고서) |
| 2 | 데이터베이스 설계 | **완료 — 로컬 테스트 100/100 통과, 실제 Supabase 미실행** |
| 3 | 지도 기반 기본 웹앱 | **구현 완료 — 단위 테스트 29/29, 빌드 성공, 실제 카카오 지도·휴대폰 미검증** |
| 4~10 | 차량·위험정보 관리, 수집, 판정 엔진, 경로 탐색, GPS, 실증 | 미착수 |

## 구성

- `db/` — PostgreSQL + PostGIS 스키마, 권한(RLS), 테스트. 자세한 내용은 [`db/README.md`](db/README.md)
- `web/` — 지도 기반 웹앱. 자세한 내용은 [`web/README.md`](web/README.md)
- `SETUP.md` — GitHub·카카오·Cloudflare·Supabase 연결 방법

## 안전·데이터 원칙

- "안전" 판정을 내리지 않는다. 구간은 통행불가 / 주의 / 미확인 / 제한없음 확인 4단계로만 표시한다.
- "확인됨(verified)"은 현장 실측(L1) 또는 관리기관 공식 자료(L2)로 검증 절차를 거친 경우에만 부여한다.
- 출동 주소, 대원 위치, 경로 이력, 현장 사진은 저장하지 않는다.
- 초기 개발비 0원: 무료 서비스는 무료 한도 안에서만 쓰고, 유료 설정은 켜지 않는다.

## 비밀값 관리

API 키, Supabase `service_role` 키, DB 비밀번호는 이 저장소에 절대 올리지 않는다. `.gitignore`가 `.env` 파일을 막아 두었다.
